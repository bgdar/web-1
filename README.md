# web-1 (Iseng-iseng Project) 😁😁

Ini sebenarnya bukan web sungguhan, lebih ke iseng-iseng aja. Proyek ini dibuat dengan menggunakan **HTML**, **CSS**, dan sedikit **Vanilla JavaScript**. Silakan cek langsung di link berikut:

🔗 [https://fotofolio-1-amoy6ongy-bgdars-projects.vercel.app/](https://fotofolio-1-amoy6ongy-bgdars-projects.vercel.app/)

---

## Teknologi yang Digunakan 🛠️

- **HTML**: Untuk struktur dasar website.
- **CSS**: Untuk styling dan tampilan visual.
- **JavaScript**: Untuk interaktivitas sederhana.

---

## Fitur ✨

- **Responsive Design**: Tampilan yang menyesuaikan dengan berbagai ukuran layar.
- **Simple Animations**: Beberapa animasi sederhana menggunakan CSS.
- **Lightweight**: Ringan dan cepat karena hanya menggunakan vanilla JavaScript.
